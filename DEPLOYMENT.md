# Deployment

Deploy the Vite application to Cloudflare Pages.

- Repository: `DT-09/Vesper`
- Production branch: `main`
- Root directory: `web`
- Build command: `npm run build`
- Build output directory: `dist`

The public product website is served at `/`; the learner workspace is served at `/workspace`.

Do not treat a successful Git push as proof of a production deployment. Verify the Pages deployment status and test both routes after deployment.
