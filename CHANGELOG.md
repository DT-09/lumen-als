# Changelog

## 1.2.1 — maintenance pass

- Added upload-size preflight checks before reading file contents into application memory.
- Applied frontend error, upload-validation, accessibility, mobile-layout and math-expression safeguards to both shipped HTML entry points.
- Verified Python tests, static JavaScript syntax, and the included retrieval/refusal evaluation fixture.

## 1.2.0 — release candidate

- Replaced the conventional single-page layout with a cinematic dark application shell and a projected spatial concept universe.
- Added interactive concept selection, zoom/orbit controls, a keyboard entry path, concept-list alternative and reduced-motion behavior.
- Added dedicated Learn, Practice, Library, Math Lab, Progress and Evaluation screens.
- Added a self-contained canvas function plotter that works without a third-party graphing API key.
- Connected source ingestion, tutoring, practice grading, learner estimates and evaluation counters to the existing FastAPI endpoints.
- Added a Learning Decision Trace view using actual grading/source/model response fields and explicit limitations.
- Added a Cloudflare Pages Function proxy for the separately hosted FastAPI backend and clarified the two-part deployment architecture.
- Updated deployment, privacy, evaluation and AI-disclosure documentation to avoid claiming that static Pages hosting runs the Python backend.

## 1.1.0 — baseline

- Source-aware retrieval, citation locators, heuristic practice, per-browser workspace isolation option and curated evaluation fixtures.
