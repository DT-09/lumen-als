STEMPROOF / WORKFLOWS
EDITORIAL OPERATIONS

From question submission to an auditable decision.

Use one repeatable workflow for routine pre-publication checks and for investigating disputed assessment items.

WORKFLOW A / PRE-PUBLICATION

Question-bank quality pass

Upload the bank

Import an existing CSV or JSON export with stable item IDs and answer keys.

Run deterministic checks

Re-solve supported questions and recalculate selected physics items.

Review the exception list

Prioritise defects and unresolved cases. Inspect evidence before changing source content.

Export the audit

Keep the report with the content release and reviewer decisions.

WORKFLOW B / DISPUTE REVIEW

Investigate a challenged answer

Identify the item

Use the original item identifier and the exact published version.

Reproduce the check

Re-run the relevant rule using the supplied values and assumptions.

Record the decision

Approve, reject, correct or defer the finding with an editor's note.

Preserve the record

Export the evidence and reviewer disposition for the editorial trail.

The current application stores audits as local JSON files. Production deployments handling confidential question banks need authenticated access, tenant isolation, retention policy and persistent database controls before customer use.
