VERIFICATION METHODS

Every result has a rule. Every rule has a boundary.

The system is designed to be inspectable. It reports what it actually checked and refuses to overstate what the check proves.

SUPPORTED METHODS

Current verification coverage.

Initial release is focused on structured mathematics and physics items. Natural-language interpretation is not silently inferred.

01

Single-variable equations

Compute the solution set for a supported equation and check whether the supplied answer belongs to it. Multiple-solution sets are retained in evidence.

Independent solve
02

Symbolic expression equivalence

Simplify the difference between the reference expression and supplied answer. A zero difference supports equivalence within the accepted symbolic domain.

Symbolic check
03

Newton's second law

Recalculate acceleration as net force divided by positive mass. The initial release expects force in newtons, mass in kilograms and answer in m/s².

Numerical check
04

Constant-acceleration kinematics

Recalculate final velocity or displacement from initial velocity, acceleration and elapsed time using the selected model.

Numerical check
05

Multiple-choice key consistency

Check that key fields agree and option labels are valid. This is not an independent solution and therefore remains a review item when fields agree.

Consistency only
IMPORTANT LIMIT

Verification is not omniscience.

STEMPROOF does not yet validate arbitrary word problems, diagrams, proofs, ambiguity, curriculum alignment, psychometric properties or pedagogical quality. A correct answer key can still belong to a defective question. Human review remains part of the process.
