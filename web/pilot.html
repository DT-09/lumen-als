THE PILOT

Start with a small, structured sample.

The first evaluation is designed around a limited set of supported assessment items. It demonstrates whether deterministic checks can add value to your existing editorial process before any broader deployment is discussed.

PROPOSED PILOT SCOPE

Up to 50 structured items

Mathematics equations and expressions, plus selected Newton's second-law and constant-acceleration physics calculations.

01
Input review

Confirm that a redacted CSV or JSON sample fits the supported schema.

02
Automated audit

Generate rule-based findings, calculation evidence and explicit review outcomes.

03
Editorial handoff

Export the evidence and record your team's accept/reject/correct decisions.

YOU PROVIDE

A structured sample

Question IDs, prompts, supported mathematical representation or physics values, and your current answer key.

STEMPROOF RETURNS

An inspectable audit

Verified matches, detected mismatches, unresolved items and reproducible evidence for each finding.

YOU DECIDE

Whether it earns a place

Compare the output with your existing process. No accuracy, savings or recovery claim is assumed in advance.

DATA HANDLING

Do not send confidential assessment material yet.

The current release does not include customer authentication, tenant isolation, contractual retention controls or a secure file-transfer portal. Initial evaluations should use public, synthetic or properly redacted sample content. A production data workflow must be agreed before confidential material is accepted.
