Evaluation dimensions
01
Retrieval quality

Measure whether known-answer queries retrieve the expected source chunk; report Recall@k and MRR with the test-set size.

02
Grounding and abstention

Test answerable questions, unrelated questions, misleading term overlap and unsupported answer types.

03
Assessment validity

Test answer keys, numerical tolerances, units and short-answer grading agreement.

04
Adaptation and regression

Check that recorded answers update the expected topic and that changes do not break existing behavior.

Run the test suite

From the project directory, install requirements and run the automated tests. Evaluation results should be regenerated against the exact release candidate.

python -m pytest -q
python evaluate.py
Do not overclaim.
Passing curated fixtures shows behavior on those fixtures only. It does not prove general accuracy or educational effectiveness.
