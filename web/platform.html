STEMPROOF / PLATFORM
PLATFORM ARCHITECTURE

A verification layer for the assessment lifecycle.

STEMPROOF ingests structured question banks, runs independent checks on supported item types, records the evidence and routes unresolved cases to reviewers.

SYSTEM DESIGN

Small surface area. Explicit rules.

The platform is deliberately bounded. Each automated finding maps to a named verification rule, rather than an opaque overall confidence score.

Ingest and normalize

Accept CSV or JSON question-bank exports. Validate required fields, parse nested values and retain item identifiers.

Route by item type

Send algebraic equations and expressions to the symbolic engine; route selected physics problems to explicit numerical models.

Produce a finding

Record the rule, inputs, independently computed result, supplied answer and the exact comparison.

Review and export

Let an editor approve, reject, correct or defer a finding. Export PDF, CSV and JSON audit records.

ENGINE

Restricted parser

Mathematical expressions pass through a restricted AST grammar. Arbitrary function calls and code execution are rejected.

RECORD

Traceable evidence

Each result preserves the method and inputs needed to reproduce the check.

BOUNDARY

Explicit uncertainty

Unsupported or malformed items are marked for review, not passed by default.
